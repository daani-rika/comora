# Моя комора

Український PWA-застосунок для домашніх запасів. Фронтенд: HTML, CSS і JavaScript без збірки. Спільна база працює через Google Apps Script та приватну Google Таблицю.

## GitHub Pages

У Settings → Pages оберіть Deploy from a branch, main, / (root). Сайт використовує відносні шляхи та підтримує розміщення в підкаталозі репозиторію.

Під час першого входу на новому пристрої введіть сімейний PIN. Він перевіряється сервером і запам’ятовується в цьому браузері. Запаси, фото й сам серверний PIN у репозиторії відсутні.

Зміни одразу відображаються в інтерфейсі та зберігаються у фоні. Черга переживає перезавантаження й відновлюється після втрати мережі. На іншому пристрої зміна з’явиться після підтвердження сервера та оновлення стану.

На Android відкрийте HTTPS-адресу в Chrome та скористайтеся встановленням застосунку / додаванням на головний екран. Для сканера потрібен дозвіл на камеру.
